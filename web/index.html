A desktop buddy that films your app tests for you

It records only the app you are testing, starts and stops by itself, and turns the run into short MP4 clips for a portfolio. Plus a focus timer with statistics, notes with reminders, a clipboard history that skips secrets, and screenshots you can draw on. Works offline.

Play with it

This is the app's real interface, running in your browser on made-up data. Click the buddy to open it, drag it around, stroke it with the mouse, right-click it. Record the sample window, start the timer, write a note, change the buddy's look. Nothing leaves your browser.

In the desktop app the buddy floats over all your windows and the recorder really captures them. A browser can't do either, so here they are simulated; everything else is the same code as the app.

What it does

Records one window, not the screen

Tell it "record any window whose title contains Note Organizer". It starts when the window opens, stops when it closes, joins quick relaunches into one file and skips the idle parts. Mark good moments with one click on the buddy, then cut clips or a short movie in the built-in editor, without ffmpeg.

A focus timer with honest statistics

Time your work, see each day's timeline and the last 30 days, with the apps you used. Pauses, sleep and clock changes never count as work.

A buddy that grows

Every timer minute is XP. Levels unlock 72 rewards: 27 shapes, colours, eyes, hats and effects. It waves, falls asleep, follows your mouse and giggles when you pet it.

Everyday tools

Screenshots you can draw on and blur, notes with checklists and reminders, a clipboard history that never saves passwords or API keys, and send-only email through your own account.

My role

Product and design

I picked the problem (filming AI test runs of my own apps), wrote the specs and made the UX calls: match windows by title, screenshots from buttons only, a simple mode and a first-run tour for beginners, and cutting features that didn't earn their place (GIF export, the spellchecker, an unfinished AI tab).

Quality

Two rounds of adversarial audits with parallel AI reviewers (robustness, security, performance on a 4 GB PC, beginner UX) found about 140 issues, and a third confirmation round found no serious ones; each fix came with a test. Then a manual test plan in standard QA format: 72 test cases and a defect log, all run on Windows.

How it was built

The code was written in pair-programming with an AI assistant (Claude). Vanilla JavaScript on Electron, no framework, strict security (sandboxed pages, no network except sending email), and logic kept in small tested modules. That is also why this demo can run the app's real pages.
